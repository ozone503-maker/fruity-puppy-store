# Character models

These are the official models for merch catalog photos. Use the reference image. Do not invent a new face.

When you make a product photo, the character wears the actual item. Keep the body, colors, face, and proportions from the guide. Only the clothing changes.

## Ipo

Pink dog. Long floppy ears, blue eyes, black nose, pink fur. Fruity Puppy and Kudoken.

Reference: `store/characters/ipo.webp`

## Gold Hawaiian

Gold humanoid robot. Leopard-print fedora, black headphones, brown sunglasses, black mustache, turquoise bead necklace. Gold segmented arms and legs.

Reference: `store/characters/gold-hawaiian.webp`

## Rusty Fedora

Weathered grey robot. Brown fedora, yellow eyes, rusted white belly plate, brown leather jacket. Stocky.

Reference: `store/characters/rusty-fedora.webp`

## Blue

Blue alien. Large smooth head, big brown eyes, slight smile, long thin arms.

Reference: `store/characters/blue-alien.webp`

## Red Leaf

Red scaled creature. Pointed ears, crest on the head, wide smile, clawed feet.

Reference: `store/characters/red-leaf.webp`

## Toad

Large brown toad. Warty skin, heavy brow, broad body.

Reference: `store/characters/toad-mint.webp`

## Pink Frog

Tan frog. Big orange-brown eyes, slight smile, webbed feet.

Reference: `store/characters/frog-pink.webp`

## Rules

- Match the reference. Same face, same colors, same body.
- Put the product on them. Tee, hoodie, visor, clogs, whatever the listing is.
- One character per product photo unless the user asks for a group.
- Ipo is the default for Fruity Puppy and Kudoken. The others are available for any brand.
- Names in this file that are descriptive (Gold Hawaiian, Rusty Fedora, Blue, Red Leaf, Toad, Pink Frog) stay until the user gives the real name. Then update this file.
